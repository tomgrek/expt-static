After downloading

Linux — mark the AppImage executable and run it: 

chmod +x PhysBox-Native-*.AppImage
./PhysBox-Native-*.AppImage

Windows — run the installer and launch PhysBox Native from the Start menu. SmartScreen may warn on first run while the build's signature reputation is still new.

Sign in from the app's account menu to pick up your cloud saves. Copilot keys and the theme live in %APPDATA%\physbox-native on Windows and ~/.config/physbox-native on Linux.

Connect an AI agent (MCP)

PhysBox: MCP is the companion Model Context Protocol server. It runs locally, relays JSON over a WebSocket on port 3142, and lets an agent drive Mesh, Volt and Etch directly — no browser automation. Install it once: 

pip install physbox-mcp

Then point your client at it. Open PhysBox (desktop or web) before starting a session — it registers with the relay as soon as it loads.

Claude — for Claude Code, run claude mcp add physbox-mcp -- physbox-mcp --stdio, or write the block below to .mcp.json in your project root. For Claude Desktop, put the same mcpServers block in %APPDATA%\Claude\claude_desktop_config.json (Windows) or ~/Library/Application Support/Claude/claude_desktop_config.json (macOS). 

{
  "mcpServers": {
    "physbox-mcp": {
      "type": "stdio",
      "command": "physbox-mcp",
      "args": ["--stdio"]
    }
  }
}

VS Code — add .vscode/mcp.json to your workspace (VS Code uses servers, not mcpServers), then start the server from the Start lens above the entry and pick it up in Copilot Chat's agent mode: 

{
  "servers": {
    "physbox-mcp": {
      "type": "stdio",
      "command": "physbox-mcp",
      "args": ["--stdio"]
    }
  }
}

Antigravity — add the same server to ~/.gemini/antigravity/mcp_config.json, then restart the IDE (or reload the agent chat session) to register the tools. If you run the server inside WSL, launch it through wsl.exe and replace <your-wsl-distro> with your distribution name: 

{
  "mcpServers": {
    "physbox-mcp": {
      "command": "C:\\Windows\\system32\\wsl.exe",
      "args": ["-d", "<your-wsl-distro>", "physbox-mcp", "--stdio"]
    }
  }
}

On Windows, Antigravity reads %USERPROFILE%\.gemini\config\mcp_config.json, which is often write-restricted. Hard-link it to the writable copy once, in PowerShell: 

Remove-Item -Path "$env:USERPROFILE\.gemini\config\mcp_config.json" -Force -ErrorAction SilentlyContinue
New-Item -ItemType HardLink -Path "$env:USERPROFILE\.gemini\config\mcp_config.json" `
         -Target "$env:USERPROFILE\.gemini\antigravity\mcp_config.json"
